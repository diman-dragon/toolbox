# Toolbox

Мультитул-приложение для Android: Capacitor 6 + Vite + TypeScript, без UI-фреймворка.
Инструменты: **Уровень**, **Угломер**, **Шаблоны углов**, **Высотомер**, **Дальномер**, **Площадь**, **Окружность**, **Металлоискатель**, **Компас**, **Отвес**, **Линейка**.
Тёмная и светлая темы, настройки (шестерёнка на главном экране).

## Сборка APK без Android Studio

1. Создайте репозиторий на GitHub и запушьте проект в ветку `main`.
2. Откройте вкладку **Actions** → **Build Android APK** (запускается сам при пуше, либо кнопкой *Run workflow*).
3. Когда сборка завершится, скачайте артефакт **toolbox-debug-apk** внутри запуска, распакуйте и установите `app-debug.apk` на телефон
   (разрешите установку из неизвестных источников).

Папка `android/` в репозиторий не коммитится: CI создаёт её командой `npx cap add android`,
затем `scripts/patch-android.sh` включает «экран не гаснет».

## Разработка в VS Code (нужен Node 20+)

```bash
npm install
npm run dev
```

В браузере датчиков нет, поэтому через 1.5 с включается симулятор: **мышь — наклон**, клавиша **E** — «телефон стоит на ребре».

## Уровень

- **Лёжа** — круглая ампула, две оси. **На ребре или стоя** — горизонтальная ампула; режим переключается сам.
- Значение: °, % или мм/м (нажмите на цифры или кнопку единиц).
- «В нуле» (±0.1°): зелёный фон и вибро.
- **Калибровка** — на ровной поверхности экраном вверх; проверка — поверните телефон на 180°.
- **Hold** замораживает показания. **Звук** — тон растёт при приближении к нулю.
- **Оси ⇄** — если пузырёк убегает в противоположную сторону (зависит от устройства), инвертируйте знаки осей.
- Поворот экрана учитывается, блокировки ориентации нет.

## Угломер

Два режима (переключатель сверху):

- **В плоскости** — телефон стоит вертикально, показывается угол ребра экрана к горизонту, от −180° до +180°.
  Чтобы измерить угол между двумя поверхностями: приложите ребро к первой, нажмите **Ноль**, приложите ко второй.
  Рядом с кратными 45° цифры становятся зелёными, срабатывает лёгкое вибро.
- **Склон** — телефон лежит экраном вверх на склоне (крыша, пандус, лестница): угол в градусах, процентах и в виде 1:N.

Калибровка нуля и «Оси ⇄» берутся из настроек Уровня, отдельно калибровать не нужно. Поворот экрана учитывается.

## Шаблоны углов

Выберите 15°, 30°, 45°, 60° или 90°: на экране пунктиром рисуется шаблон, акцентной линией — текущий угол ребра телефона.
Совпадение в пределах ±0.5° — зелёный экран и вибро. «Ноль» задаёт опорную поверхность.

## Высотомер

Введите расстояние до объекта, наведите верхнее ребро на верх и нажмите «Зафиксировать верх»; для точности — ещё и на основание.
Формулы: `h = d·(tg α₁ − tg α₂)`, а без «низа» `h = d·tg α₁ + высота глаз`.

## Дальномер

Наведите ребро на основание объекта: `d = высота глаз / tg(угол вниз)`. Высота глаз задаётся в настройках.

## Площадь и окружность

Площадь — набор прямоугольников со знаком «+/−» (комната сложной формы, выемки). Окружность — диаметр ⇄ радиус ⇄ обхват и площадь круга.

## Металлоискатель и компас

Используют магнитометр. В Android доступ идёт через собственный плагин `native-src/MagnetometerPlugin.java.tpl`
(WebView по умолчанию не отдаёт магнитометр); `patch-android.sh` добавляет его при сборке. Нет датчика — инструмент сообщает об этом.
Металлоискатель реагирует на изменение модуля поля относительно «нуля» (железо, сталь, магниты), цветные металлы не видит.
В браузере работает симулятор: мышь — азимут, клавиша **M** — «металл».

## Отвес

Камера с красной линией истинной вертикали по акселерометру: совместите её со стеной, косяком или колонной. «Стоп-кадр» замораживает картинку.
Нужно разрешение камеры (`patch-android.sh` добавляет его в манифест; кадры нигде не сохраняются и не передаются).

## Линейка

Деления в мм/см или в дюймах (по настройке единиц). Масштаб по умолчанию 160 px на дюйм; для точности — «Калибровка» по банковской карте (85.6 мм).

## Настройки

Тема (системная / светлая / тёмная), метры или футы, высота глаз, вибро, сброс калибровки уровня.

## Публикация

- **Debug APK** собирается на каждый пуш (артефакт `toolbox-debug-apk`).
- **Подписанный релиз (APK + AAB для Google Play)** собирается автоматически, если в Settings → Secrets заданы
  `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` (команды создания ключа — в начале `.github/workflows/android.yml`).
  Номер сборки (`versionCode`) = номер запуска workflow, `versionName` берётся из `package.json`. Сохраните keystore: без него обновления в Google Play невозможны.
- Для карточки в магазине: приложение офлайн, не собирает и не передаёт данные, запрашивает только доступ к камере для «Отвеса» (политика конфиденциальности — одна строка об этом).

## Иконка

Транспортир с иглой и горизонтальная ампула уровня. Исходник — `public/icon.svg`.
Для Android это адаптивная иконка из векторов (`native-res/res`), с монохромным слоем для тем Android 13+ и запасными PNG для старых версий.
`scripts/patch-android.sh` копирует всё это в проект при сборке. Изменить дизайн: поправьте геометрию в `scripts/make-icon.py`
и выполните `python3 scripts/make-icon.py` (нужен Pillow). Превью — `assets/icon-preview.png`.

## Добавить инструмент

1. Создайте `src/tools/<id>/index.ts` с `export default async function (root: HTMLElement): Promise<Tool>`.
2. В `src/core/registry.ts` поставьте `enabled: true` и `load: () => import('../tools/<id>')`.
