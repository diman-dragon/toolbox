# Toolbox

Мультитул-приложение для Android: Capacitor 6 + Vite + TypeScript, без UI-фреймворка.
Сейчас активны **Уровень** и **Угломер**; дальномер, компас, отвес и линейка стоят в сетке как «скоро».

## Сборка APK без Android Studio

1. Создайте репозиторий на GitHub и запушьте проект в ветку `main`.
2. Откройте вкладку **Actions** → **Build Android APK** (запускается сам при пуше, либо кнопкой *Run workflow*).
3. Когда сборка завершится, скачайте артефакт **toolbox-debug-apk** внутри запуска, распакуйте и установите `app-debug.apk` на телефон
   (разрешите установку из неизвестных источников).

Папка `android/` в репозиторий не коммитится: CI создаёт её командой `npx cap add android`,
затем `scripts/patch-android.sh` включает «экран не гаснет».

## Разработка в VS Code (нужен Node 20+)

```bash
npm install
npm run dev
```

В браузере датчиков нет, поэтому через 1.5 с включается симулятор: **мышь — наклон**, клавиша **E** — «телефон стоит на ребре».

## Уровень

- **Лёжа** — круглая ампула, две оси. **На ребре или стоя** — горизонтальная ампула; режим переключается сам.
- Значение: °, % или мм/м (нажмите на цифры или кнопку единиц).
- «В нуле» (±0.1°): зелёный фон и вибро.
- **Калибровка** — на ровной поверхности экраном вверх; проверка — поверните телефон на 180°.
- **Hold** замораживает показания. **Звук** — тон растёт при приближении к нулю.
- **Оси ⇄** — если пузырёк убегает в противоположную сторону (зависит от устройства), инвертируйте знаки осей.
- Поворот экрана учитывается, блокировки ориентации нет.

## Угломер

Два режима (переключатель сверху):

- **В плоскости** — телефон стоит вертикально, показывается угол ребра экрана к горизонту, от −180° до +180°.
  Чтобы измерить угол между двумя поверхностями: приложите ребро к первой, нажмите **Ноль**, приложите ко второй.
  Рядом с кратными 45° цифры становятся зелёными, срабатывает лёгкое вибро.
- **Склон** — телефон лежит экраном вверх на склоне (крыша, пандус, лестница): угол в градусах, процентах и в виде 1:N.

Калибровка нуля и «Оси ⇄» берутся из настроек Уровня, отдельно калибровать не нужно. Поворот экрана учитывается.

## Иконка

Транспортир с иглой и горизонтальная ампула уровня. Исходник — `public/icon.svg`.
Для Android это адаптивная иконка из векторов (`native-res/res`), с монохромным слоем для тем Android 13+ и запасными PNG для старых версий.
`scripts/patch-android.sh` копирует всё это в проект при сборке. Изменить дизайн: поправьте геометрию в `scripts/make-icon.py`
и выполните `python3 scripts/make-icon.py` (нужен Pillow). Превью — `assets/icon-preview.png`.

## Добавить инструмент

1. Создайте `src/tools/<id>/index.ts` с `export default async function (root: HTMLElement): Promise<Tool>`.
2. В `src/core/registry.ts` поставьте `enabled: true` и `load: () => import('../tools/<id>')`.
