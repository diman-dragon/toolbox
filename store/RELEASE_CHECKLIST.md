# Чек-лист выпуска (DataLaw Design, часть 2)

## Один раз
- [ ] Аккаунт разработчика и платёжный профиль; публичное имя — DataLaw Design.
- [ ] Приложение создано, включён **Play App Signing**.
- [ ] Ключ загрузки (upload key) создан и лежит вне репозитория (+ личная резервная копия):
      `keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000`
- [ ] Секреты GitHub: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
- [ ] Отладочный ключ `keystore/toolbox-debug.jks` — только для тестовых APK, **никогда** не для Google Play.

## Каждый выпуск
1. Поднять `version` в `package.json` (единственное место). `versionCode = major×10000 + minor×100 + patch` (2.1.0 → 20100).
2. `node tests/run.mjs` и `npm run build` — зелёные.
3. Workflow **release.yml** → артефакт `.aab`.
4. Play Console → внутреннее тестирование → загрузить `.aab`, добавить тестеров, раздать коды (`node tools/make-codes.mjs 20`).
5. Товары: `premium_lifetime`, `tip_tea`, `tip_cat_treat`, `tip_cat_food`; license testing; проверить покупку и восстановление.
6. Ответы — из `PLAY_CONSOLE_ANSWERS.md`, тексты — `LISTING_RU.md` / `LISTING_EN.md`, графика — `store/icon-512.png`, `feature-graphic-1024x500.png`, `screenshots/` (все три темы).
8. Для личного аккаунта: закрытый тест (12 тестировщиков, 14 дней), затем производство.

## Проверка на устройстве
- [ ] Установка, первый запуск, все три темы, смена языка.
- [ ] Уровень: пузырёк плавный, цифры не мигают, калибровка в два шага, поворот экрана.
- [ ] Угломер, шаблоны, отвес: углы верны на столе и на стене; сверка с эталоном.
- [ ] Высотомер и дальномер: калибровка горизонта, замеры известного объекта.
- [ ] Компас, металлоискатель, шумомер, сканер, линейка.
- [ ] Жесты: окна закрываются свайпом вниз, касанием фона и «назад»; кнопки работают после возврата на экран; нет мигания.
- [ ] Premium: пробный период, блокировка после него, покупка, восстановление, код, чаевые, реакция котика.
- [ ] Политика и условия открываются; версия в «О приложении» верна.
