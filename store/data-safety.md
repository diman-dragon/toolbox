# Форма «Безопасность данных» (Play Console → Политика приложения)

| Вопрос | Ответ |
|---|---|
| Собирает ли приложение пользовательские данные? | **Нет** |
| Передаёт ли данные третьим лицам? | **Нет** |
| Шифрование при передаче | не применимо (данные не передаются) |
| Можно ли запросить удаление данных | не применимо (данные только на устройстве) |
| Политика конфиденциальности (URL) | адрес страницы `docs/index.html` на GitHub Pages |

Камера и микрофон обрабатываются только на устройстве, без записи и передачи — по правилам Play это не «сбор».

## Заявление о разрешениях (если запросят)
- `CAMERA` — высотомер, дальномер, отвес, сканер QR/штрихкодов (основная функциональность).
- `RECORD_AUDIO` — шумомер (анализ уровня в реальном времени, запись не ведётся).
- `MODIFY_AUDIO_SETTINGS` — настройка аудиовхода для шумомера.

## Анкета возрастного рейтинга
Насилия, азартных игр, покупок, общения между пользователями, UGC, местоположения нет → ожидаемо «3+ / Для всех».

## Остальные разделы
Реклама: нет · Доступ к приложению: без ограничений (входа нет) · Целевая аудитория: 18+ или «все», не детская · Приложение для новостей/здоровья/финансов: нет.
