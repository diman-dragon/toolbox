# Ответы для Play Console

| Раздел | Ответ |
|---|---|
| Data safety | Данные не собираются и не передаются. Камера и микрофон обрабатываются только на устройстве, без записи и передачи. |
| Рейтинг IARC | Во всех вопросах «Нет». |
| Целевая аудитория | 18+ (запасной вариант 13+). Приложение не для детей. |
| Декларации | Реклама — нет; доступ к фото/видео — нет; новости/здоровье/финансы — нет. |
| Доступ к приложению | Без ограничений, входа нет. |
| Служба переднего плана | Не используется. |
| Target SDK | 36 |
| Встроенные покупки | `premium_lifetime` (4,99 €/$, непотребляемый), `tip_tea`, `tip_cat_treat`, `tip_cat_food` (чаевые, потребляемые). |
| Политика конфиденциальности | URL страницы политики на сайте (после публикации сайта). |

## Разрешения и обоснование

- `CAMERA` — высотомер, дальномер, отвес, сканер QR и штрихкодов (основная функциональность). Кадры не сохраняются и не передаются.
- `RECORD_AUDIO` — шумомер: анализ уровня звука в реальном времени, запись не ведётся.
- `MODIFY_AUDIO_SETTINGS` — настройка аудиовхода шумомера.
- `com.android.vending.BILLING` — покупки Premium и чаевые (через Play Billing Library).
- Доступа к файлам, местоположению, контактам нет. Все `uses-feature` для камеры, автофокуса и микрофона — `required=false`.
